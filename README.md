Telemetry MQTT subscriber
=========================


Telemetry project root: https://github.com/dimon12345/telemetry


Receives messages from sensors via the MQTT protocol and inserts them into a
PostgreSQL database.

Copy and edit .env.example and config.json.example and edit

Start test ./scripts/docker_test.sh

Start service ./scripts/docker.up.sh
